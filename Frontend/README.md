# 🏠 AI Wall Crack Detection & Cost Estimation System

An AI-powered web application that detects wall cracks from uploaded images, classifies crack severity, estimates repair costs, and generates detailed repair reports.

---

## 🚀 Features

- 🔍 AI-based wall crack detection
- 📷 Image upload and preview
- 📦 ZIP image upload support
- 📊 Crack severity classification
  - No Crack
  - Paint Crack
  - Plaster Crack
  - Structural Crack
- 📐 Wall and crack measurements
- 🧱 Material quantity estimation
- 💰 Repair cost estimation
- 👷 Labour cost calculation
- 📄 Downloadable analysis report
- 📈 Dashboard with analysis statistics
- 🕒 Analysis history
- 📱 Responsive user interface

---

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/AI-Wall-Crack-Detection-System.git
```

### Backend Setup

```bash
cd backend
pip install -r requirements.txt
python app.py
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## 📷 Workflow

1. Upload wall image or ZIP file
2. AI detects cracks
3. Crack severity is classified
4. Material quantities are calculated
5. Labour cost is estimated
6. Total repair cost is generated
7. Download the analysis report
